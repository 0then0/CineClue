Угадайте фильм по его связям с другими картинами. Каждая попытка сравнивает год выхода, режиссёров, жанры, актёров, длительность, страны и студии. В ежедневном режиме все игроки получают одну загадку и восемь попыток.

![CineClue на английском: сравнение фильмов с постерами, портретами, логотипами студий и индикаторами совпадений](docs/screenshot.jpg)

## Возможности

- **Фильм дня:** общая загадка, которая обновляется в 00:00 UTC, сохранение прогресса и статистика в браузере.
- **Без границ:** случайные загадки, три уровня сложности и 42 подборки фильмов.
- **Вызов:** загадайте фильм и отправьте другу ссылку на игру.
- **10 000 фильмов:** каталог включён в репозиторий, для запуска не нужен ключ API киноисточника.
- **Наглядные сравнения:** стрелки, подсветка совпадений, портреты, постеры и флаги стран.
- **Подсказки:** первая открывается после трёх неудачных попыток, вторая после семи.
- **Русский и английский интерфейс**, поиск с клавиатуры, мобильная вёрстка, светлая, тёмная и системная темы.
- **Результаты без спойлеров:** отправка через системное меню или копирование в буфер обмена.

## Запуск через Docker

Установите [Docker Compose](https://docs.docker.com/compose/install/), клонируйте репозиторий и запустите приложение:

```sh
git clone https://github.com/0then0/CineClue.git
cd CineClue
docker compose up --build
```

Откройте [localhost:5173](http://localhost:5173). При первом запуске приложение создаёт базу данных, применяет миграции и загружает включённый каталог. Первичный импорт может занять несколько минут. Данные PostgreSQL сохраняются между перезапусками.

Эта конфигурация Compose предназначена для локальной разработки. Публичное размещение, резервное копирование и обновление описаны в [руководстве по развёртыванию](docs/DEPLOYMENT.md).

## Как играть

Найдите фильм по русскому, английскому, оригинальному или альтернативному названию и выберите результат. Новая попытка появляется первой.
- **Полное совпадение:** совпадает число или весь набор значений категории.
- **Частичное совпадение:** есть общие актёры, режиссёры, жанры, страны или студии. Совпавшие значения выделены.
- **Близкое значение:** разница не больше трёх лет или десяти минут.
- **Стрелки:** загаданный фильм новее или старше, длиннее или короче выбранного.
- **Нет совпадений:** общих значений нет либо число выходит за пределы близкого диапазона.

После трёх и семи неудачных попыток можно выбрать доступную подсказку: жанры, актёра, десятилетие выхода или другой фильм режиссёра. Закрытие окна выбора не расходует подсказку. Ответ открывается после победы или всех восьми попыток.

Прогресс ежедневной игры хранится на сервере и связан с анонимным cookie браузера. Статистика хранится в localStorage этого браузера. Очистка cookie удаляет доступ к текущим играм; очистка localStorage удаляет локальную статистику. Регистрация не нужна.

## Локальная разработка

Используйте **Node.js 24.15+ в пределах ветки 24.x**, **pnpm 12.14.0** и **PostgreSQL 16–18**. Основная версия PostgreSQL в проекте: 18.

```sh
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env
docker compose up -d db
node --env-file=.env scripts/import_movies/seed.ts
pnpm dev
```

Если приложение уже запущено через Compose, остановите сервис `app`, прежде чем запускать сервер разработки на том же порту: `docker compose stop app`.

```sh
pnpm check     # Проверка каталога, типов, lint, модульные и UI-тесты, production-сборка
```

Интеграционные тесты, исправление данных и отправка pull request описаны в [руководстве для участников](CONTRIBUTING.md).

## Постеры и портреты

Включённые метаданные изображений позволяют показывать постеры и портреты TMDB без ключа API при запуске. Сами изображения загружаются с CDN поставщика. Чтобы обновлять метаданные или искать отсутствующие изображения, сохраните API Read Access Token в переменной `TMDB_API_TOKEN` файла `.env`, затем перезапустите `pnpm dev` или выполните:

```sh
docker compose up -d --force-recreate app
```

Токен остаётся на сервере. При наличии подходящих файлов приложение также использует изображения Wikimedia Commons с разрешёнными лицензиями. Источники и условия использования доступны в каждой карточке; для отсутствующих изображений предусмотрены читаемые заглушки. Подробнее: [данные и изображения](docs/DATA.md).
